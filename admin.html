First time here? This panel uses Supabase Auth, so before it works you need to:
1. Fill in SUPABASE_URL / SUPABASE_ANON_KEY in this file (and in the main site file) with your project's values.
2. In Supabase Dashboard → Authentication → Users, create one user for yourself — that's the only account that can log in here.
3. Create the products, reviews, orders, custom_requests, gallery, and extras tables (ask me for the SQL any time).
4. In Storage, create two Public buckets: product-images and gallery-images, so photos you upload here can show on the main site.
